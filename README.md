# Shoply v1 — DM Ordering Assistant: Implementation Plan

## Context

A busy Ghanaian WhatsApp seller loses hours a day to repetitive buyer DMs — *is this available, what size, how much, where do you deliver, how do I pay*. The readme in the backend specifies an assistant that has that entire conversation in the shop's own voice, so the seller only ever sees a finished result:

> "Order confirmed — Ama (024xxxxxxx) wants the Black Heeled Sandal, size 39, ×1. Paid GHS 320 via MoMo. Deliver to East Legon, [address]. Buyer notes: 'by Friday please.'"

That notification is the product. Everything below serves it. See backend README for more details.
